# 图片转拼豆设计图

纯前端本地图片处理工具，上传图片自动生成拼豆配色方案与网格设计图。

## 功能

- 本地上传图片（JPG/PNG），零网络请求
- 自动原图抠图 + 去白底
- RGB 欧式距离颜色匹配（196 色 Mard 标准色卡）
- 每个拼豆上标注对应色号
- 自动生成配色清单（排除辅助豆 H1/H2）
- 一键下载高清 PNG 设计图纸（含行列号、配色表）
- 全屏查看，支持缩放查看细节
- 响应式布局，适配手机、平板、电脑

## 处理流程

| 步骤 | 名称 | 说明 |
|------|------|------|
| 1 | 上传图片抠图 | 根据背景容差裁剪原图四边空白边缘 |
| 2 | 去白底 | 将白色/浅色像素设为透明（alpha=0） |
| 3 | 像素化 | 将抠图后的原图压缩到目标网格尺寸 |
| 4 | 颜色量化 | RGB 欧式距离匹配 Mard 色卡，透明像素标记为背景 |
| 5 | 杂色去除 | 消除孤立像素点（可选，默认关闭） |
| 6 | 限制颜色数 | 合并低频色到高频色（可选，默认不限） |
| 7 | 裁剪空白背景 | 去除网格四周纯背景行和列 |
| 8 | 绘制拼豆图 | 渲染到 canvas（圆形/方形、网格线、色号） |
| 9 | 更新统计 | 计算拼豆数、颜色数、配色清单 |

## 参数控制

| 参数 | 说明 |
|------|------|
| 预设宽度 | 网格预设宽度（16/24/32/48/64），高度按图片比例自适应 |
| 颜色简化 | 去除低频稀有颜色，替换为邻域主色（默认关闭） |
| 杂色去除 | 消除孤立像素点（默认关闭） |
| 背景容差 | 关闭/低/中/高，控制抠图与去白底强度 |
| 最大颜色数 | 限制最终使用的颜色种类数（默认不限） |
| 拼豆形状 | 圆形 / 方形 |
| 网格线 | 无 / 细线 / 粗线 |
| 网格线颜色 | 黑色 / 灰色 / 白色 |
| 显示色号 | 显示 / 不显示 |

## 部署

纯静态项目，仅需 `index.html`、`style.css`、`script.js` 三个文件。

支持：GitHub Pages / Cloudflare Pages / Gitee Pages / Nginx / 任意静态托管服务。

无需后端、无需构建、无需配置。

## 技术

- 原生 HTML + CSS + JavaScript + Canvas
- RGB 三维欧式距离颜色匹配
- 邻域主导色杂色消除
- 原图自动抠图 + 去白底
